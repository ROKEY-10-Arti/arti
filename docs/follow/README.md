# 사용자 추종 (follow)

- 패키지: `src/follow/arti_follow`
- 일정 (노션 간트): 11/16 ~ 11/18
- 관련 요구사항: [common/requirements.md](../common/requirements.md) — 자유 관람, 분실 처리, 작품 해설 시작 조건
- 원본 플로우차트: 노션 `tracking_pc_ver3.drawio`

## 범위

관람객을 추적 대상으로 등록하고, 지도 위 위치를 계속 추정해서 약 80 cm 거리를 유지하며 따라간다.
작품 관람 구역에서 멈추면 해설 시작 조건을 판정하고, 대상을 놓치면 분실 처리를 한다.

## 개발 순서 (플로우차트 기준)

| # | 단계 | 내용 | 상태 |
|---|---|---|---|
| 1 | 기반 준비 | 공통/환경 | 진행 중 |
| 2 | 관람객 등록 | 스캔 시작 → 탑CAM 인식 → 등록 → 등록 성공 보고 | |
| 3 | 위치 추정 | 지속 재식별 → 탑CAM·Depth 매칭 → 거리 측정 → map 좌표 | |
| 4 | 추종 주행 | 거리 유지하며 이동 (80 cm) | |
| 5 | 작품 설명 | 5초 정지 → 반원 구역 판정 → 설명 / 이탈 시 중지 | |
| 6 | 분실 처리 | 최종 좌표 이동 → 회전 탐색 → 대기 → 재등록 | |
| 7 | 종료·복귀 | 배터리 부족·종료 구역 → 종료 보고 → DOCK | |
| 8 | 안정화 | 통합 테스트 | |
