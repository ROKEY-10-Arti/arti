# nav2_follow 실주행 결과 (6 Run)

`nav2_follow`(주행을 Nav2에 맡긴 추종 노드)로 실제 robot1을 6가지 상황에서 주행한 기록.
수치는 각 Run의 bag을 읽어 계산한다 (저장소에 검증 코드를 넣지 않음, 분석은 bag만 읽음). 문제 상황은 맨 아래 **트러블슈팅**에 증거와 같이.

- 날짜: (주행 날)        주행·관람객: (이름)        커밋: (`git log -1 --format=%h`)
- 노드 설정: `src/arti_follow/config/nav2_follow.json` — **유지 거리 1.2 m** (서기 1.25 m 안, 다시 출발 약 1.35 m), 놓침 1.5 s, 대기 10 s
- Nav2 설정: `src/common/arti_bringup/config/nav2_follow.yaml` — 최고 0.3 m/s, 회전 0.8 rad/s, 탐색 회전 0.63 rad/s
- bag: `~/arti_bags/nav2_test/run1` ~ `run6` 아래 `<날짜_시각>/` (카메라 영상 없음)
- 그림: `docs/follow/img/nav2_test/runN_timeline.png`(시간 그래프), `runN_map.png`(지도 경로)

## 1. 주행 방법

```bash
# 한 번만: localization (떠 있으면 생략) → Nav2 (우리 설정, 기본 설정 nav2는 먼저 끔)
ros2 launch turtlebot4_navigation localization.launch.py namespace:=$ARTI_ROBOT1_NS map:=$ARTI_MAP
ros2 launch turtlebot4_navigation nav2.launch.py namespace:=$ARTI_ROBOT1_NS \
  params_file:=$(ros2 pkg prefix arti_bringup)/share/arti_bringup/config/nav2_follow.yaml
# Run마다 (N = 1~6): 켜고 → 액션 보내고 → Run이 끝나면 launch Ctrl-C (bag 닫힘)
ros2 launch arti_follow tour_nav2.launch.py bag_dir:=~/arti_bags/nav2_test/runN
ros2 action send_goal /robot1/arti/start_tour arti_interfaces/action/StartTour "{mode: FREE}" --feedback
```
- **Run 시작 때 로봇은 도크 위.** Run 1·2·3·4·6은 마지막에 관람객이 **출구 구역**에 들어가면 로봇이 스스로 도크로 돌아간다 → 그대로 다음 Run.
  Run 5는 LOST로 끝나므로 로봇을 손으로 도크에 올려 둔다.
- 매 Run: 등록은 키오스크 앞에서 로봇이 키오스크 쪽을 본 뒤 앞에 서서 제스처.
- 시나리오 구간이 바뀔 때 **시계 시각 메모** (아래 Run 메모 칸). 멈춘 거리를 줄자로 재면 같이 메모.
- 멈추기: `ros2 topic pub --once /robot1/follow/enable std_msgs/msg/Bool "{data: false}"` / 액션 Ctrl-C / 로봇 버튼.

## 2. 시나리오와 합격 기준

| Run | 상황 | 관람객이 하는 일 | 보는 수치 (합격 기준) |
|---|---|---|---|
| 1 | 혼자 잘 주행 | 등록 → 한 바퀴. **그림1·그림2 앞에서 멈춰 설명을 끝까지 들음**, **그림3·그림4는 멈추지 않고 지나감** → 출구 | 설명: 그림1·2 **설명함**, 그림3·4 **설명 안 함** / 설명 중 로봇 이동 **< 10 cm** / 선 거리 **1.2~1.35 m** / 너무 가까움(< 0.65 m) **0 %** / 섰다 다시 움직임 **0회** / 놓침 **0회** / 도킹 성공 |
| 2 | 가운데 장애물 | 통로 가운데 막대기를 두고 그 옆을 지나감 (로봇이 피해야 하는 위치) → 출구 | 장애물까지 최소 거리 (로봇 표면) **> 0.05 m**, 부딪힘 **0** / 우회 때문에 뒤처진 최대 거리 **< 2.5 m** / 장애물 앞에서 멈춘 시간 / 놓침 |
| 3 | 사람 사이 지나침 | 다른 사람 1~2명이 서 있거나 걷는 사이를 지나감 → 출구 | 인식 대상 ID 바뀜 **0회** (다른 사람을 따라가지 않음) / 사람·장애물 최소 거리 / 놓침 횟수 |
| 4 | 벽 뒤로 사라지고 기다림 | 벽(가운데 벽 모서리) 뒤로 갑자기 들어가 그 자리에서 기다림 → 로봇이 찾으면 다시 걸음 → 출구 | 놓침 → **SEARCH** (마지막 위치로 이동 → 회전) → 다시 찾기까지 **s** / 회전 각도 / 다시 찾은 단계 (SEARCH 중·WAIT 중) |
| 5 | 아예 사라짐 | 벽 뒤로 사라져 다시 안 나타남 (로봇이 볼 수 없는 곳) | SEARCH 회전 **≥ 360°** / WAIT **10 s** / 결과 **lost**, 놓침부터 LOST까지 **약 30 s** / arti/tour_end 1번 |
| 6 | 빨리 걷기 | 평소보다 빨리 (약 1 m/s) 한 바퀴 → 출구 | 관람객 최고 속도 vs 로봇 최고 0.3 m/s / 최대 뒤처진 거리 / 놓침 횟수·다시 찾기 / 관람객이 멈춘 뒤 다시 1.2 m로 붙기까지 **s** |
