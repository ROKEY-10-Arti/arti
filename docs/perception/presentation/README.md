## 2. 발표자용 핵심 키워드 인덱스 (헷갈림 방지 치트시트)

### A. 용어·알고리즘 빠른 사전
| 키워드 | 10초 설명 (입에 붙이는 표현) | 발표 시 주의사항 (오개념 방지) |
|---|---|---|
| **ByteTrack (1차 모션 추적)** | 칼만 필터로 다음 프레임 위치를 예측하고, IoU(박스 겹침)가 큰 박스를 같은 사람으로 잇는 1차 추적기 | 화면 밖 장기 이탈·급회전·교차 시 위치 예측이 빗나가 타겟을 놓침 (`10.1% ~ 25.6%`) |
| **304D HSV 히스토그램** | 사람 영역 픽셀의 색상·채도(`18×16 H-S`)와 명도(`16 V`) 분포를 합쳐 만든 304차원 외형 지문 | 배경을 빼고 옷/몸통 픽셀에서만 뽑아야 비슷한 환경의 타인과 섞이지 않음 |
| **Anchor + EMA 이중 기억** | 최초 등록 시점의 원본 특징(**Anchor**)은 고정 보존하고, 최신 외형(**Recent**)만 지수이동평균(`EMA`)으로 천천히 갱신해 둘 다 비교 | 단독 1인 추적 & 유사도 `>= 0.60`일 때만 `EMA` 갱신 (`α=0.04`) → 타인 혼입 오염 방지 |
| **Bhattacharyya 분포 유사도** | 두 히스토그램 분포가 얼마나 겹치는지 재는 유사도 (`1 - Bhattacharyya 거리`, `0.0~1.0`) | *초기 초안의 "코사인 유사도"가 아니라 **Bhattacharyya 분포 유사도**가 실제 구현* |
| **Adaptive 4상태 관리** | **`SAFE`**(안정) · **`GUARD`**(혼잡 시 타인 박스 마스킹 `exclude_boxes`) · **`SEARCH`**(유실 후 재탐색) · **`RECOVERED`**(2프레임 연속 확인 복귀) | **`COEX`**(멀리 떨어져 공존한 타인 ID 차단) 덕분에 단순 Re-ID 대비 오잠금을 1/4 이하(`5.4%`)로 억제 |
| **3D 공간-외형 가중 결합** | 외형 유사도에 LiDAR 기반 3D 이동 반경(`1.35 m/s` 보행 반경) 점수를 가중 평균해 최종 후보 판별 | **혼잡(`GUARD`)**: 외형 `0.60` + 공간 `0.40` / **복귀(`SEARCH`)**: 외형 `0.65` + 공간 `0.35` |
| **Pose `BBox 폴백` & `edges` 보완** | 근접 시 하반신 관절이 안 잡혀 기존 Pose가 일반 사각형 박스로 되돌아가던 현상(`21.4%`)을, 상완(`어깨-팔꿈치`)·단측 어깨 등 **마커 연결선 1:1 `max` 비교**로 해결(`3.5%`) | 기존 몸통 사각형 1개 대신 **보이는 관절 연결선끼리만 1:1 대응 비교**하는 것이 핵심 |
| **최종 모델: `YOLOv8n-pose`** | `v8n / 11n / 26n × Det / Seg / Pose` 9종 × 5모드 × 8-GT 교차 검증 결과 **종합 정확도 1위(`83.3%`)·최저 오잠금(`5.4%`)·최고 추론 속도(`4.50ms`)** | 초기 테스트 모델(`yolo26n-pose`)에서 실측 검증 후 **`yolov8n-pose.pt`**로 최종 교체 완료 |

### B. 꼭 외울 핵심 숫자 인덱스
- **단일 이탈·재등장 (`one_man_gt`, 1,450f)**: 모션 단독 `25.6%` → Adaptive Re-ID **`99.9%`** (`TGT 0.80 [RECOVERED]`)
- **다인 교차 혼잡 (`pose_estimate2_gt`, 1,996f)**: 모션 단독 `10.1%` → Adaptive Re-ID **`96.1%`** (단순 Re-ID `93.1%`)
- **타인 오잠금 억제 (`model_benchmark` 6타겟, 4,038f)**:
  - 알고리즘 비교: `Task-ReID` `20.4%`, `BoT+ReID` `30.8%` → `Adaptive (26n-pose)` `10.8%` → **`Adaptive (v8n-pose)` `5.4%`** (*단순 Re-ID 대비 1/4 이하*)
  - 태스크 비교: `Det` **`39.1 ~ 43.1%`**, `Seg` **`42.2 ~ 44.3%`** → **`YOLOv8n-pose` `5.4%`** (*1/7 ~ 1/8 수준*)
- **Pose 연결선(`edges`) 보완 효과 (`YOLOv8n-pose`)**:
  - 8-GT 종합 정확도: `78.9%` → **`83.3%`** (`+4.4%p`, 전체 9모델 1위)
  - 6타겟 평균 유지율: `62.9%` → **`71.3%`** (`+8.4%p`)
  - BBox 폴백 비율: `21.4%` → **`3.5%`** (`-17.9%p`)
  - GPU 추론 속도(RTX 4070, 6타겟): **`4.50ms`** (vs `26n-pose 6.72~7.74ms`, `26n-seg 7.90ms`)

## 3. 페이지별 실전 발표 스크립트 (`로키 지능1 detection.pdf` 기준)

### [21p] ① 비전 기반 사용자 재인식 추적 알고리즘 (`ByteTrack → Adaptive Re-ID`)

> **화면 포인트**: 상단 `1→2→3→4` 흐름도 → 좌측 4카드 → 우측 ① 타겟 유지율 그래프 → 우측 ② 비타겟 오잠금률 그래프

**[도입 — 문제 정의]**
> "저희 Detection 파트의 핵심 목표는 관람객이 화면 밖으로 잠깐 나갔다가 돌아오거나 다른 사람과 스쳐 지나가도, **처음 등록한 바로 그 관람객을 끝까지 놓치지 않고 추적하는 것**입니다.  
> 기본 YOLO 모델은 매 프레임 '사람이 어디 있는지'는 찾지만, 이전 프레임에 있던 바로 그 사람인지는 기억하지 못합니다.

**[1차 모션 추적(ByteTrack)과 한계 — 우측 ① 회색 막대]**
> 그래서 먼저 **칼만 필터로 이동 범위를 예측하고 IoU가 높은 박스를 잇는 ByteTrack**을 적용했습니다.  
> 하지만 오른쪽 첫 번째 그래프를 보시면, 사람이 화면 밖으로 오래 나가거나(`one_man_gt`) 여러 사람과 겹쳐 교차할 때(`pose_estimate2_gt`) 움직임 예측만으로는 타겟을 놓쳐 유지율이 **25.6%**, **10.1%**까지 급감했습니다.

**[2차 외형 기억(304D HSV + Anchor/EMA) — 상단 3단계 · 좌측 2카드]**
> 이를 보완하기 위해 움직임이 아니라 **타겟의 외형 특징**을 기억하는 Re-ID를 결합했습니다. 사람 영역 픽셀에서 색상·명도 분포인 **304차원 HSV 히스토그램**을 추출해 **Bhattacharyya 분포 유사도**로 비교합니다.  
> 이때 조명이나 자세 변화에도 원래 대상을 잃지 않도록, **등록 당시 특징(`Anchor`)을 고정 보존**하면서 1인 추적 구간에서 안정적으로 확인될 때만 **`EMA(지수 이동 평균)`로 최신 외형(`Recent`)을 함께 갱신해 두 특징을 동시에 비교**합니다.

**[Adaptive 4상태 + 3D 공간 결합 — 상단 4단계 · 좌측 3~4카드 · 우측 ② 그래프]**
> 하지만 단순히 외형만 비교하면 타겟이 화면에 없을 때 비슷한 색 옷을 입은 다른 사람을 타겟으로 오잠금하는 문제가 생깁니다. 오른쪽 두 번째 그래프 주황·빨강 막대처럼 단순 Re-ID 계열은 비타겟 오잠금률이 **20.4%에서 30.8%**에 달했습니다.  
> 이를 해결하기 위해 **Adaptive 4상태 관리**와 **3D 공간 융합**을 구현했습니다. 이미 타겟과 함께 화면에 공존했던 다른 사람은 **`COEX` 목록으로 차단**하고, 혼잡 시에는 타인 박스를 마스킹(`GUARD`)한 뒤 **외형 유사도와 LiDAR 기반 3D 이동 반경 점수를 가중 평균**해 최종 타겟을 판별합니다. 복귀 시에도 **2프레임 연속 확인(`SEARCH`)**을 거치도록 설계해, 단일 이탈 유지율 **99.9%**, 다인 교차 **96.1%**를 지키면서 오잠금률을 단순 Re-ID의 **1/4 이하인 5.4%**까지 억제했습니다."

### [22p] ② 외형 추출 모델 선정 근거 & 근접 Pose 마스킹 보완

> **화면 포인트**: 상단 `Det / Seg / Pose` 3카드 → 좌측 4카드 → 우측 ① 태스크별 오잠금률 그래프 → 우측 ② Pose 보완 전·후 그래프

**[태스크 선정 이유 — 상단 3카드 · 우측 ① 그래프]**
> "다음은 외형 히스토그램을 **어떤 YOLO 태스크 모델로 추출할지** 결정한 근거입니다.  
> 먼저 일반 **Detection** 모델은 속도는 빠르지만 사각형 바운딩 박스 안의 벽·배경 픽셀까지 함께 뽑히기 때문에, 오른쪽 첫 번째 그래프처럼 6타겟 실측 기준 타인 오잠금률이 **39.1%에서 43.1%**로 높게 나타났습니다.  
> 반대로 **Segmentation**은 배경은 정교하게 도려내지만 연산 부하가 크고, 로봇이 가까워지거나 신체가 일부 가려졌을 때 상·하의를 해부학적으로 구분하지 못해 오히려 **42.2%에서 44.3%**의 높은 오잠금률을 보였습니다.

**[Pose 채택 & 근접 주행 연결선(`edges`) 보완 — 좌측 1~2카드 · 우측 ② 그래프]**
> 이에 저희는 배경을 거르면서도 신체 부위를 구분할 수 있는 **Pose 모델**을 채택해 오잠금을 **1/7~1/8 수준**으로 낮췄습니다.  
> 다만 초기 테스트 중 실제 로봇이 관람객 가까이에 붙었을 때 하반신 관절이 프레임 밖으로 빠져 기존 Pose가 일반 사각형 박스로 되돌아가는 **`BBox 폴백`이 21.4%나 발생**하는 한계를 발견했습니다.  
> 이를 해결하기 위해 몸통 사각형이 안 만들어지더라도 **상완(`어깨-팔꿈치`)이나 한쪽 어깨-골반 같은 마커 간 연결선 단위로 마스크를 생성하고, 보이는 부위 연결선끼리만 1:1 `max` 비교**하도록 보완했습니다.  
> 그 결과 두 번째 그래프처럼 **BBox 폴백률은 21.4%에서 3.5%로 급감**했고, 6타겟 평균 유지율도 **62.9%에서 71.3%**로 `+8.4%p` 상승했습니다.

**[최종 모델 버전 결정 — 좌측 3~4카드]**
> 모델 버전(`YOLOv8n / 11n / 26n`)까지 포함한 8개 GT 전체 비교 결과, **`YOLOv8n-pose`가 종합 정확도 83.3%로 전체 1위, 타인 오잠금 5.4% 최저, 추론 속도도 4.50ms로 가장 빨라** 최종 운용 모델로 결정했습니다."

### [23p] 실제 주행·추적 실행 화면 검증 (`one_man_gt` · `pose_estimate2_gt`)

## 4. Q&A 대비 예상 질문 인덱스

| 예상 질문 | 핵심 답변 요약 (근거 수치 포함) |
|---|---|
| **Q1. 최신 `YOLO26n-pose` 대신 `YOLOv8n-pose`를 최종 선택한 이유는?** | 8개 실측 GT 종합에서 `v8n-pose`가 **`83.3%`(1위, `26n-pose 79.4%`)**, 6타겟 평균 **`71.3%`**, 비타겟 오잠금 **`5.4%`(최저, `26n 10.8%`)**, GPU 추론 **`4.50ms`(vs `26n 6.72~7.74ms`)**로 정확도·안정성·속도 모두 우위였기 때문. |
| **Q2. `Adaptive ReID`가 단순 `Task-ReID`보다 오잠금이 1/4로 줄어든 비결은?** | `Task-ReID`는 타겟이 사라진 뒤 비슷한 옷을 입은 다른 사람에게도 재잠금(`20.4~30.8%`)되지만, `Adaptive`는 **공존 타인 차단(`COEX`)** + **2프레임 연속 확인(`SEARCH`)** + **3D LiDAR 이동 반경 점수 결합**으로 헛잠금을 **`5.4%`**까지 억제함. |
| **Q3. `Segmentation`은 배경을 정밀하게 자르는데 왜 오잠금이 `42~44%`로 높은가요?** | 사람이 가까워지거나 일부 가려졌을 때 실루엣을 단순 높이 비율(35%·70%)로만 3등분하므로 얼굴/목이 상의로, 상의가 하의로 밀려 들어가 오매칭되며, 연산 지연(`7.90ms`)도 가장 큼. |
| **Q4. 조명 변화나 일부 신체 가림에는 어떻게 대응하나요?** | 초기 등록 특징(**Anchor**)과 **EMA(`Recent`)** 이중 비교로 조명·자세 변화에 적응하고, **`Pose edges`**로 보이는 관절 연결선(예: 오른쪽 어깨~팔꿈치)끼리만 1:1 비교해 부분 가림에도 강건함. |
